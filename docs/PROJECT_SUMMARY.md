# Personal AI —— 3 分钟版

> 详细地图见 `docs/PROJECT_MAP.md`。本文只回答一件事：**这东西到底是什么。**

---

## 一句话

**一个跑在你自己电脑上的个人智能层。**
前面接大模型，后面有自己的长期记忆和"对你的理解"。
它不只是记住你说过什么，还会判断某句话是不是你的长期规律——
拿不准的**不当作事实**，放进"待验证"等你认可；
认可之后还要继续攒够证据，这个理解才真正能影响它之后怎么回答你。

---

## 它已经能做到什么

**聊天**：同步和流式都支持，记住上下文接得上之前聊的。

**记住你**：你说的话、你看的东西（摄像头/图片）会存下来。
这些是**过去**。

**理解你**：从重复行为里归纳出假设，比如
"你最近总在深夜写作业"。每条假设带置信度，而且**只能靠你的真实行为或
你自己的话来加分减分**——它自己想的证明不了它自己。

**发现变化**：你说"我改成早上了"，它会更新理解，
并让你看到**为什么**这么理解（附你的原话和时间）。

**后台推测**：用户不说话时在本地扫事件，发现"是不是变了"。
但它**只能提，不能用**——

> 这是整个项目最重要的设计原则：
> **AI 的猜测不能改变 AI 对你的正式行为策略。**

推测出来的东西一律进"我正在思考"，你点"对"也只是
"值得继续观察"，不是"这就是事实"。要真正生效，得跨天攒够 2 个独立来源的证据。

**真的改变行为**：这是最近才做对的一件事。
以前它把理解一股脑塞进提示词，模型爱怎么理解怎么理解。
现在它先**判断**、再**执行**：

> 你说过"这类题先给我提示" → 这次它会主动只给思路不给答案
> 但你说"还是不会，直接告诉我吧" → **这一轮**直接给答案

长期记忆是对你的尊重，不是命令。

**知道自己现在几点**：读系统时钟，每轮实时，
用户说"现在是1999年"也改不动它。时间**永远不落库**——它是"现在"，不是"过去"。

## 它绝对不做的事

| 不做 | 为什么 |
|---|---|
| 预测你未来会做什么（**Forecast / Prediction**） | 会给用户一种被监视的感觉，且不可验证 |
| 主动打扰你（**Intervention**） | 占位实现，`decide()` 恒返回"不打扰" |
| 让推测指挥行为 | 猜测一旦能指挥行为，就等于系统在自己编造你 |
| 假设自己证明自己 | 证据来源白名单里没有假设 |
| 自动变成"事实记忆" | 需要用户确认 + 跨天多来源 |
| 展示原始思维链 | 只给产品化的"处理摘要"，而且没有可靠来源时**根本不显示** |

**没有 Agent。** `agent/tools.py` 里只有"查记忆"类只读工具，
文档原话是"未来 Agent 编排在这里扩展"——
也就是**现在没有**：无任务队列、无 ReAct 循环、无 tool-calling 循环。
而且这个模块**根本不在运行链路**上（只有 smoke 测试引用它）。

**没有 Personality、没有 Forecast、没有多用户、没有语音、没有向量检索、
没有联网搜索。** 全仓库无相关代码。

## 它长什么样

一个网页 + 一个桌面壳（Windows 安装包）。

界面上的几个地方：

- **聊天区** —— 回答下方有个可折叠的"处理摘要"，说清这次为什么这么答
- **我眼中的你** —— 已经确认的正式理解
- **我正在思考** —— 后台推测，轻、低强调
- **待验证** —— 需要你动手判断的候选，卡片化，有"对/不对"
- **AI 记忆** —— 你说过的话，可改可删
- **回忆库** —— 检索历史，附依据
- **过去 7 天** —— 只读周报

后三个"理解"面板刻意长得不一样：
正式理解最稳、后台猜测最轻、待验证最突出（因为要你动手）。

## 30 秒判断一个功能该不该做

> 它是否让这个 AI **更理解这个人**，或者让它**更可靠地利用这种理解**？

只是增加功能而没增强理解 → 排后面，或不做。
