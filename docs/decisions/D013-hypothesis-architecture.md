# D013 — Personal Hypotheses 架构（V0.3）

日期：2026-09-27 ｜ 状态：已实施（`docs/PLAN_v0.3.md`）

## 决策

1. **假设与事实物理隔离**：新建 `hypotheses` / `hypothesis_evidence` /
   `hypothesis_log` 三表，不复用 `context_entries`（成长模型 §15 铁律）。
2. **规则归纳，不用 LLM**：R1（同 activity 事件 ≥3）+ R2（共享二连字的
   interaction 条目 ≥2，连通分组）。确定、可测、零成本、不脑补用户。
3. **置信度显式数学**：初始 0.50 / 支持 +0.08 / 反证 -0.25 /
   用户否决置 0.25 / clamp [0,1] / 独立源<2 锁 0.70。增量式更新，
   否决后旧支持不复活。
4. **独立源保守定义**：event 按 id；context 按日折叠（同日多条=1 源）；
   correction 按"条目+日"。宁可低估，不自嗨。
5. **确认 ≠ 高置信度**：confirm 只改状态。否决词扫描先剥离
   "是不是/有没有/记错"，防"记错了"误伤（实测抓到的真坑）。
6. **进 Prompt 降权标记**：独立段 + "不是事实"声明 + tentative/confirmed
   才进；`approach` 语义不动（D007）。

## 被拒绝的候选项

- LLM 读记忆总结画像（不可测、易脑补、V0.4+ 实验方向）
- 向量/RAG 语义聚类（记忆还薄，位置已留 D003）
- R3 纠正主题归纳（纠正走"联动反证"已覆盖，主题归纳等数据厚）
- 假设直接进相处方式指令（违反"假设不是事实"，只允许降权段）
- confirm 联动提置信度（破坏"确认≠置信"分离）
- 同日多条算多源（宽松，自嗨风险，否决）

## 教训

- `CONTRADICT_DELTA = -0.25` 配减法写出"反证加分" bug，被 H1 精确值测试
  当场抓住——数学常量必须配精确断言。
- 否决词"错了"误伤"记错了"：自然语言规则必须配边界测试。
