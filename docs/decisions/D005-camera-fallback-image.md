# D005：V0.1 感知主路径 = 手动图片，摄像头尽力而为

- 日期：2026-09-26
- 状态：已接受
- 背景：任务书允许"摄像头抓帧 / 手动图片输入"。实测本机内置摄像头 OpenCV 打不开（`Camera index out of range`，设备管理器存在 `Integrated Camera` 但状态 Unknown，疑为 Win11 相机隐私开关未对桌面应用开放）。
- 决定：
  1. 主路径：Web 上传图片（一定能用）；
  2. 摄像头按钮保留，调用失败时给出明确提示和修复指引，不阻塞流程；
  3. 摄像头被系统隐私挡住属于用户设置问题，由用户在 系统设置→隐私→相机 里打开"允许桌面应用访问相机"，不通过改注册表代用户做隐私决定。
- 理由：任务书原则"少问先做" + "不阻塞核心闭环"；摄像头链路代码已具备，开关一开即可用。
- 影响：`perception/camera.py` 捕获异常并返回友好错误；UI 提示文案。
