# D018 — V0.5.3 值得信任地记忆（设计决策）

日期：2026-09-30 ｜ 状态：**已实施**（测试 `tests/test_trustworthy.py` 10 项 +
全量 305 通过 + 五套 acceptance 全过）

## 背景

V0.5.2 的 7 天真机验证（transcript 全程记录）证明"记得准"成立，
但暴露两个 P0 信任失败：Day 4 别记回答层失败、Day 6 配额静默丢记忆。
按冻结决议"先定位根因，不扩功能"，V0.5.3 只修这两件，不进 V0.6。

## 决策

1. **别记用"整轮隐藏"而不用"对象提取"**：单轮多主题时让模型判断
   "哪个别记"必错（Day 4 张冠李戴实锤）。整轮隐藏把这道题直接取消——
   没有对象可误认。可预测性优先于精细度，注释锁定语义。
2. **history 分两份**：UI 回看的那份原样（不删记录），进 prompt 的那份过滤。
   "不删记录"和"不引用"是两回事，分开满足。占位符占位不断连贯。
3. **配额满转假设池而不用淘汰制**：淘汰=删用户记忆，违 V0.5.2 确立的
   "状态列不删除"铁律。转假设是"宁可少记"的字面实现：
   memory 没记（诚实），但没丢（可转正）。
4. **不给用户发"记忆满了"提示**：deposit 在回答后跑，结果进不了本轮回答；
   下轮注入状态会打扰用户，违沉默原则。日志可审计就够了，
   这是后台卫生，不是用户议题。
5. **P1 缺口留 V0.5.4**：衍生计划失效、自然确认不进假设链、验证零触发——
   真实但不是信任崩塌，本版扩散就是 scope creep。克制。
6. **溢出假设四不准**（用户拍板）：低优先级/不引用/不验证/不参与 pattern，
   只当未来分析材料。否则就是把"静默丢弃"换成"假设垃圾桶"。
7. **event 防火墙是 V0.5.4 首项候选**：统一 memory firewall 治理所有长期存储入口。
   本版不修（保回归面），但不许遗忘。

## 被拒绝的候选项

- span 级精确隐藏（只藏别记那句话）：精细但不可测，多主题边界无穷，
  下版议，本版整轮一刀切。
- 配额满淘汰低分记忆（删数据；否决，见上）。
- 配额满回答里提示用户（通道不存在 + 打扰；否决，见上）。
- 别记轮 history 不追加（断连贯，下轮模型失忆整轮；否决）。
- 顺手修 event 防火墙（P1，路径已探明但非 P0；留 V0.5.4 一起议，
  本版动 event 会扩大回归面）。
