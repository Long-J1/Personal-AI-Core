# D006：记忆判断的优先级——“解析失败保守记忆”高于重要度阈值

- 日期：2026-09-26
- 状态：已接受
- 背景：`MemoryPolicy.should_remember()` 需要决定两件事的先后：重要度阈值拦截 vs 解析失败兜底。
- 决定：顺序为 **隐私暂停 → 解析失败（保守记忆）→ 重要度阈值**。
- 理由：
  1. 解析失败的事件 importance 是默认值 0.2，不是模型的真实评价——若阈值先跑，任何 >0.2 的阈值都会把全部失败样本静默丢掉；
  2. 任务书原则“记忆是核心资产，失败可恢复”：宁可记下原文事后清理，不可无声丢失；
  3. 阈值只对“被模型正常评价过”的事件生效，语义才正确。
- 测试：`tests/test_pipeline.py::test_memory_policy_remembers_parse_failure` 锁定该行为。
