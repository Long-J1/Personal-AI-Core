# Personal AI v0.2.0

第一个正式 Windows 安装包版本。核心闭环 + 个人上下文 + 桌面安装，普通用户双击即可使用。

## 下载

- **PersonalAI-Setup-0.2.0.exe**（110.4 MB，Windows 10/11 x64）
- SHA-256: `feed0ebf23aca58a06501794307717970d05e923e344efb190cc04155a8496ab`
- 官网下载入口：<https://long-j1.github.io/download/>

## 新增（相对 v0.1.0）

- 🖥️ **桌面安装包**：双击安装、双击启动；核心程序自动运行，无需命令行 / Python
- ⚙️ **模型设置**：本地模型（Ollama）与云端模型（OpenAI 兼容接口）界面热切换、连接测试、密钥脱敏
- 💾 **数据管理**：导出 / 本地备份 / 恢复，恢复前自动安全备份
- 🧠 **Personal Context 读写闭环**：对话读取理解、沉淀新理解、纠正即刻生效
- 🔒 程序目录与数据目录分离：卸载不删记忆，重装自动接回
- 🛡️ 端口冲突 / 启动失败 / 崩溃均有明确错误页与重试，不白屏

## 基础能力（v0.1.0）

- 感知：图片上传 / 摄像头 → 视觉模型理解为结构化事件
- 记忆：本机 SQLite，时间 / 关键词检索、删除、导出
- 回忆：「刚才 / 今天 / 上次」→ 带依据的回答
- 隐私：暂停记录开关、原图不落盘、沉默记账不进记忆库

## 已知限制

- 未购买代码签名证书：Windows SmartScreen 首次运行会提示「未知发布者」，选「更多信息 → 仍要运行」
- 仅 Windows；macOS / Linux 在路线图中（未实现）

## 环境

- 使用本地模型需先安装 [Ollama](https://ollama.com)；或在软件内配置云端模型
