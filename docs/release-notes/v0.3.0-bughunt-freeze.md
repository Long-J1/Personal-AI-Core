## 三、Accepted trade-off（8 个，不修，理由）

1. 归纳跑在请求路径：数据量小（200 事件扫描毫秒级），后台线程反而引入 sqlite 复杂性。
2. 纠正联动依赖模型先提取：纠正的定义如此，无提取即无纠正；另配手动编辑通道已覆盖。
3. 跨文件注入 store：生产默认同库，文档已声明；独立文件是测试形态。
4. 并发建双胞胎 scope：单机单进程 + 实例锁，够用。
5. Ollama 弱管理："尽力而为"是文件头合同，不动。
6. 午夜窗口重叠 / 停用词子串：D003 已认领的已知 trade-off。
7. 版本号仍 `0.2.0`：故意。动版本牵动 installer 文件名 + 官网 + SHA，等最终封版统一做。
8. 重试点重试（M7）、单次端口尝试 TOCTOU、慢启动自家 Core 被当异物：概率低，修的代价（90s×N 轮询、误杀自家 Core）大于收益；注释已写实。
